# ACE v0.18.0

ACE v0.18.0 provides the developer-accepted MATLAB/Fortran atmospheric dynamics
milestone with normalized source directories and shared NetCDF input.

## Included

- MATLAB reference and Fortran implementation, with reproducible Manus 208
  three-hour singleACE and twelve-hour multiACE comparisons.
- Stable native precipitation evaluation for Fortran real32 and real64.
- Tested mixed-precision Fortran configuration: default-real32 model arrays
  with binary64 PMB storage and input reads. Build instructions are in
  [the Fortran README](../../fortran/README.md); real64 remains the default.
- Comparison figures for MATLAB, corrected real64 and real32, with recorded
  developer acceptance of the inward propagation and ascending-motion response.

## Scope

Long-time real32 trajectories differ from MATLAB and real64 in local amplitude
and timing. The developer accepts the observed physical evolution for this
milestone. These cases do not establish universal numerical equality, full
water/energy budget closure or compiler portability.

The release uses ACE native simplified precipitation. P3 integration is
planned for v0.20.

See [the release record](v0.18.0.md) for acceptance, provenance and evidence.
